# Ashen Horde 2

The next version of Ashen Horde, a dark survival horde game for the phone browser: realistic 3D characters turned into Diablo 2 style sprites.

Play: https://sichdar.github.io/ashen-horde-2/

Starts from Ashen Horde version 9 (https://sichdar.github.io/ashen-horde/), which stays as it is.
